# UX Audit Checklist

A free checklist for auditing user interfaces against research-backed usability principles.

Based on the methodology used by [Interface Audit](https://interfaceaudit.com) — an AI-powered UX analysis tool.

## Quick Checklist

### Visual Hierarchy
- [ ] Primary action is visually dominant
- [ ] Information follows F-pattern or Z-pattern reading flow
- [ ] Whitespace guides attention to key elements

### Touch Targets (Mobile)
- [ ] Buttons are minimum 44x44px (iOS) / 48x48dp (Android)
- [ ] Adequate spacing between interactive elements (8px+)
- [ ] No hover-dependent interactions on touch devices

### Cognitive Load
- [ ] Forms have 5 or fewer fields visible at once
- [ ] Navigation has 7±2 items maximum
- [ ] Progressive disclosure for complex features

### Accessibility
- [ ] Color contrast meets WCAG AA (4.5:1 for text)
- [ ] All images have alt text
- [ ] Form inputs have visible labels

### Error Handling
- [ ] Error messages explain how to fix the issue
- [ ] Errors appear near the relevant field
- [ ] Success states are clearly communicated
